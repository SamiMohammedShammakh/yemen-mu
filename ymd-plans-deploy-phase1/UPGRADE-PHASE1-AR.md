# ترقية المرحلة الأولى — تعليمات التطبيق

> **لا تطبّق على النظام الفعلي قبل موافقتك الصريحة.** هذه الحزمة جاهزة ولم تُنشر.

## محتويات الحزمة
| الملف | الاستخدام |
|---|---|
| `phase1.patch` | سلسلة commits (من النسخة المسلَّمة إلى المرحلة الأولى) لتطبيقها على مستودع GitHub الذي يبني منه Render |
| `ymd-plans-source-phase1.zip` | الشيفرة المصدرية كاملة بعد التحديث (بدون vendor وبدون .env) |

## قبل أي شيء: نسخة احتياطية
1. من لوحة Aiven: خذ **Backup** يدويًا لقاعدة MySQL (أو `mysqldump --single-transaction`).
2. تأكد أن النسخة اكتملت قبل المتابعة.

## الطريقة (أ) — Render + GitHub (الإعداد الحالي)
```bash
git checkout -b phase1
git am < phase1.patch          # إن فشل التطبيق لاختلاف المستودع: استخدم ymd-plans-source-phase1.zip وقارن يدويًا
php artisan test               # أو vendor/bin/phpunit — يجب أن تنجح 51 اختبارًا
git push origin phase1
```
ثم بعد موافقتك: ادمج `phase1` في الفرع الذي ينشر منه Render. بعد البناء شغّل في Render Shell:
```bash
php artisan migrate --force
php artisan optimize:clear
```
> إن كان أمر البدء (start command) في Render يشغّل `migrate --force` تلقائيًا فسيُطبَّق الـ migration عند النشر مباشرة — لذلك خذ النسخة الاحتياطية **قبل** الدمج.

## الطريقة (ب) — cPanel
1. ارفع محتوى `ymd-plans/` فوق المجلد الحالي (لا تحذف `.env` ولا `storage/`).
2. ارفع `public_html/css/app.css`.
3. من Terminal: `php artisan migrate --force && php artisan optimize:clear`.

## ما يفعله الـ migration (`2026_09_29_000100_phase1_years_goals_hierarchy_refs`)
- **إضافي فقط**: يضيف أعمدة وجداول جديدة (`strategic_goals`, `ref_sequences`)، ولا يحذف ولا يعدّل أي عمود أو صف قائم.
- يملأ الأرقام المرجعية للبيانات الموجودة (خطط، أهداف، مبادرات، مهام) وبيانات السنوات (الاسم والتواريخ من الأرباع).
- مُختبَر على قاعدة MySQL-متوافقة: كل الجداول الـ28 مطابقة على أعمدتها الأصلية بعد الترقية، والتراجع يعيد المخطط كما كان.

## التراجع عند الحاجة
```bash
php artisan migrate:rollback --step=1 --force   # يحذف فقط ما أضافته المرحلة الأولى
```
ثم أعد نشر الشيفرة السابقة. (الأهداف الاستراتيجية والأنشطة المُنشأة بعد الترقية ستُفقد بالتراجع — لذا النسخة الاحتياطية.)

## فحص سريع بعد التطبيق
- «السنوات والأرباع»: تظهر السنوات بأسمائها وتواريخها وزر «إدارة السنة».
- «الأهداف الاستراتيجية»: يستطيع الرئيس ومسؤولة التخطيط الإضافة.
- صفحة أي خطة: يظهر رقمها المرجعي مثل `PL-2026-ENG`.
- سجل التدقيق: تظهر عمليات `strategic_goal.create` و`activity.create` عند التجربة.
