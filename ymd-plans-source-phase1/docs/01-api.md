# توثيق الواجهات (API)

الواجهات تحت البادئة `/api/v1` وتعيد JSON. تستخدم نفس جلسة الدخول (ملف تعريف الارتباط) ونفس فحوص الصلاحية المطبّقة على الصفحات عبر `App\Support\Access`، فلا يمكن الوصول عبرها إلى أي بيانات لا تظهر للمستخدم في الواجهة.

## القواعد العامة

- كل طلب يتطلب مستخدمًا مسجّل الدخول وحسابًا فعّالًا. الطلب بلا جلسة يعيد `401`.
- طلب خطة أو مؤشر خارج نطاق المستخدم يعيد `403` مع رسالة عربية، ولا يكشف اسم الخطة أو محتواها.
- المعرّف غير الموجود يعيد `404`.
- القوائم والبحث تُصفّى على الخادم بنطاق الخطط المرئية للمستخدم.
- الأرقام الرسمية تُحسب من التحديثات **المعتمدة** فقط، والربع المغلق يُقرأ من لقطة إقفاله.

## `GET /api/v1/me`
بيانات المستخدم وصلاحياته الفعلية.

```json
{
  "id": 8, "name": "م. نبيل السقاف", "email": "engineering@ymd-tr.org",
  "positions": [{"id": 7, "code": "engineering", "name": "مسؤول الشؤون الهندسية"}],
  "global_view": false, "executive_member": false, "can_review": false, "can_approve": false,
  "workspaces": [{"key": "pos:7", "label": "مسؤول الشؤون الهندسية"}]
}
```

## `GET /api/v1/plans?year=2026`
الخطط المرئية للمستخدم (صاحب المنصب: خطته فقط؛ الرئيس والتخطيط والإدارة التنفيذية: الكل).

```json
{"data": [{"id": 1, "year": 2026, "position": {"id": 7, "name": "مسؤول الشؤون الهندسية"},
  "status": "active", "status_label": "نشطة", "version": 1, "updated_at": "2026-09-26T13:26:00+03:00"}]}
```

## `GET /api/v1/plans/{id}`
هيكل الخطة: نطاق العمل، النتيجة العامة، المخاطر، الموارد، الأهداف وأوزانها، المؤشرات ومستهدفاتها الربعية (`quarter_targets`)، المشاريع والمهام. `403` إن كانت خارج النطاق.

## `GET /api/v1/plans/{id}/results?quarter=2`
نتائج الخطة حتى نهاية الربع المحدد (الافتراضي: الربع المختار في الجلسة).

| الحقل | المعنى |
|---|---|
| `period_achievement` | إنجاز الخطة مقابل المستهدف المرحلي للربع (متوسط مرجح بأوزان الأهداف المقاسة) |
| `annual_achievement` | إنجاز الخطة مقابل المستهدفات السنوية حتى تاريخه |
| `coverage` | نسبة أوزان الأهداف التي لديها بيانات معتمدة |
| `status` | `{key, label}`: `on_track` يسير حسب الخطة، `follow_up` يحتاج متابعة، `late` متأخر، `not_due` لم يستحق بعد، `no_data` |
| `source` | `live` حساب مباشر، أو `snapshot` لقطة ربع مغلق (مع `snapshot_revision`) |
| `rules` | نسخة قواعد الحالات المستخدمة وحدودها |
| `version_no` | رقم نسخة الخطة |
| `objectives[].indicators[]` | لكل مؤشر: `period` (الربع المختار) و`quarters` (1–4) و`annual` و`explain` (سطور الحساب ومصدر كل رقم) |

حقول `period` لكل مؤشر:

| الحقل | المعنى |
|---|---|
| `compare_label` | أساس المقارنة بالنص، مثل «مستهدف النصف الأول» |
| `compare_target` | المستهدف المرحلي (التراكمي للمؤشر التراكمي) |
| `compare_actual` | الفعلي المعتمد المقابل (`null` إن لم يُقس) |
| `gap` / `gap_text` | الفجوة رقمًا ونصًا |
| `achievement` | النسبة مقابل `compare_label` |
| `state` | `measured` مقاس، `not_due` لم يستحق بعد، `missing` بيانات ناقصة، `pending` بانتظار التحقق |
| `pending_count` | عدد التحديثات بانتظار التحقق (غير محتسبة) |
| `source_ids` | أرقام التحديثات المعتمدة التي بُني عليها الرقم |

## `GET /api/v1/indicators/{id}`
المؤشر وصفوف الأرباع الأربعة (كل ربع من لقطته إن كان مغلقًا) وسجل التحديثات بحالاتها.

## `GET /api/v1/search?q=نص`
بحث في الأهداف والمؤشرات والمشاريع والمهام داخل الخطط المرئية فقط.

```json
{"objectives": [], "indicators": [{"id": 1, "title": "عدد البرامج التدريبية المنفذة", "plan_id": 1, "position": "مسؤول الشؤون الهندسية", "year": 2026}], "projects": [], "tasks": []}
```

## `GET /api/v1/exports`
آخر 50 ملفًا: ملفات المستخدم نفسه، أو كل الملفات لأصحاب الرؤية الشاملة. يتضمن رابط `download` الذي يعيد التحقق من الصلاحية عند كل تنزيل.

## مسارات التنزيل (غير JSON)

| المسار | الوصف |
|---|---|
| `GET /exports/preview?scope=&format=&plan_id=&quarter=&subject_id=` | معاينة رأس الملف قبل إنشائه (فحص صلاحية) |
| `POST /exports` | إنشاء الملف (فحص صلاحية ثانٍ) وتسجيله |
| `GET /exports/{uuid}/download` | تنزيل (فحص صلاحية ثالث بالحالة الحالية) وتسجيل التنزيل |
| `GET /attachments/{id}` | تنزيل دليل مرفوع بعد فحص صلاحية الخطة |

قيم `scope`: `plan_full`، `plan_quarter`، `results_annual`، `results_quarter`، `objective`، `indicator`، `project`، `year_package`، `org_summary`. التفاصيل في [دليل التنزيل](04-downloads.md).

## أوامر سطر الأوامر

| الأمر | الوصف |
|---|---|
| `php artisan alerts:generate [year]` | توليد تنبيهات التحديثات المستحقة والمهام المتأخرة والمؤشرات تحت المستهدف والأدلة المنتظرة (مجدول يوميًا 07:00) |
| `php artisan year:create 2028` | إنشاء سنة تخطيط بأرباعها الأربعة |
