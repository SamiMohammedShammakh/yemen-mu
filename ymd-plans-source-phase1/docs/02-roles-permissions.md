# دليل إدارة المناصب والصلاحيات

## المبدأ

تُطبَّق الصلاحيات **على الخادم في كل طلب**: الصفحات، البحث، التقارير، واجهات API، المرفقات، وروابط التنزيل. إخفاء زر في الواجهة ليس هو الحماية؛ حتى لو كتب المستخدم الرابط أو رقم الخطة يدويًا يحصل على `403`. مصدر القواعد الوحيد هو `app/Support/Access.php`.

## المناصب السبعة

| المنصب | يرى | يستطيع |
|---|---|---|
| **الرئيس** | جميع الخطط والنتائج | اعتماد الخطط، إعادتها، البت في طلبات التعديل، تفويض الاعتماد، إدارة الحسابات والإدارة التنفيذية |
| **مسؤول التخطيط والمتابعة** | جميع الخطط والنتائج | مراجعة الخطط والتوصية أو الإعادة، التحقق من الأدلة، ملاحظات المتابعة، الإجراءات التصحيحية، إنشاء السنوات، إقفال الأرباع، ضبط حدود الحالات |
| **نائب الرئيس** | خطته فقط | ما يستطيعه أي صاحب منصب. **لا يرى خطط الآخرين إلا إذا أُضيف صراحةً إلى الإدارة التنفيذية** |
| أمين السر | خطته فقط | إنشاء خطته وتعديل مسودتها وإرسالها، تحديث مؤشراته ومهامه، رفع الأدلة، طلب تعديل خطته المعتمدة، تنزيل ملفات خطته |
| مسؤول الشؤون المالية والإدارية | خطته فقط | كما سبق |
| مسؤول العلاقات العامة والإعلام | خطته فقط | كما سبق |
| مسؤول الشؤون الهندسية | خطته فقط | كما سبق |

صاحب المنصب المقيّد لا يرى أسماء خطط المناصب الأخرى ولا تفاصيلها في أي قائمة أو بحث أو تقرير.

## أدوار خاصة

| الدور | كيف يُمنح | ماذا يضيف |
|---|---|---|
| **عضو الإدارة التنفيذية** | يضيفه الرئيس (أو مدير النظام تنفيذًا لقرار موثق) من «الإدارة التنفيذية والتفويض» مع سند المنح | رؤية جميع الخطط والنتائج، لوحة الرئيس والإدارة التنفيذية، تنزيل أي خطة وتقرير شامل |
| **مفوَّض بالاعتماد** | يسجله الرئيس برقم وثيقة التفويض ومدة سريانها | اعتماد الخطط وطلبات التعديل. يرى فقط الخطط الموصى باعتمادها أو التي عليها طلب تعديل قيد القرار؛ يُحفظ رقم الوثيقة مع كل اعتماد |
| **مدير النظام التقني** | خاصية في الحساب | إنشاء الحسابات وإسناد المناصب وإيقافها. **لا يقرأ الخطط تلقائيًا**، ويرى من سجل التدقيق أحداث الحسابات والصلاحيات فقط |

لا تُمنح عضوية الإدارة التنفيذية تلقائيًا لأي منصب. كل منح أو إيقاف يسجّل: من منح، متى، السبب؛ ومن أوقف، متى، السبب. السجل لا يُحذف، ويظهر في الشاشة وفي سجل التدقيق (`executive.grant` / `executive.revoke`).

## المهام الشائعة

### إنشاء حساب وإسناد منصب
1. «الحسابات والمناصب» ← «حساب جديد».
2. أدخل الاسم والبريد وكلمة مرور (8 أحرف على الأقل بحروف وأرقام)، واختر المنصب وتاريخ بدء الإسناد.
3. عند الدخول تُفتح للمستخدم لوحة منصبه مباشرة.

### مستخدم يشغل أكثر من منصب
من صفحة الحساب ← «إسناد منصب». يظهر للمستخدم مبدّل «مساحة العمل» أعلى الصفحات، ولا يعرض إلا المساحات التي يملك صلاحيتها. «المنصب الأساسي» هو الذي تُفتح لوحته عند الدخول.

### تسليم منصب لشخص جديد
1. في حساب الشاغل السابق: «إنهاء» الإسناد بتاريخ التسليم (يبقى السجل).
2. أسند المنصب للشاغل الجديد. يرث الخطة لأن الخطة مرتبطة بالمنصب لا بالشخص، ويفقد السابق الوصول فورًا.

### إيقاف حساب
ألغِ «الحساب فعّال». يُرفض الدخول وتُنهى الجلسات الحالية عند الطلب التالي.

### إضافة نائب الرئيس (أو غيره) إلى الإدارة التنفيذية
«الإدارة التنفيذية والتفويض» ← اختر المستخدم ← اكتب سند المنح (رقم القرار أو المحضر) ← «منح العضوية». للإيقاف: اكتب السبب ← «إيقاف»؛ تُسحب الرؤية الشاملة من الطلب التالي، بما فيها تنزيل ملفات أُنشئت سابقًا.

### تفويض الاعتماد
«تفويض اعتماد الخطط» ← المفوَّض، رقم الوثيقة، تاريخ البداية والنهاية. يمكن إلغاؤه في أي وقت.

## دورة اعتماد الخطة

```
مسودة ← مرسلة لمراجعة التخطيط ← (معادة للتعديل | موصى باعتمادها) ← معتمدة من الرئيس ← نشطة ← مغلقة
```

| الإجراء | من | شرط |
|---|---|---|
| إنشاء الخطة، تعديل المسودة أو المعادة، الإرسال | صاحب المنصب | لا يُرسل إلا إذا اكتملت الخطة (انظر [06-database.md](06-database.md#قواعد-اكتمال-الخطة)) |
| إضافة ملاحظة، الإعادة للتعديل (بسبب إلزامي)، التوصية بالاعتماد | مسؤول التخطيط | الخطة مرسلة |
| الاعتماد، أو الإعادة من مرحلة التوصية | الرئيس أو المفوّض | تُحفظ نسخة جديدة `vN` بلقطة كاملة للخطة |
| التفعيل، الإغلاق | الرئيس/المفوّض أو مسؤول التخطيط | — |

بعد الاعتماد لا تُعدَّل الأهداف والأوزان والمستهدفات مباشرة؛ يُقدَّم «طلب تعديل الخطة» بسبب، ويعرض القيم القديمة والجديدة وأثره على الأرباع، ويعتمده الرئيس أو المفوّض فتُحفظ نسخة جديدة وتبقى النسخ السابقة.

## التحقق من الإنجاز

- كل تحديث يُحفظ «بانتظار التحقق» في سجل زمني لا يُعدَّل ولا يُحذف من الواجهة (الحماية في النموذج نفسه).
- مسؤول التخطيط يعتمد الدليل أو يعيده مع سبب إلزامي.
- لا يدخل أي تحديث غير معتمد في نتيجة الخطة الرسمية، ويظهر منفصلًا بعبارة «بانتظار التحقق (غير محتسب)».
