# دليل تنزيل الخطط والنتائج

## أين أجد زر التنزيل؟

| المكان | ما يمكن تنزيله |
|---|---|
| لوحة المنصب ← «تنزيل الخطة والنتائج» | الخطة كاملة، خطة الربع، نتائج الربع، النتائج السنوية، حزمة السنة |
| صفحة الخطة ← أعلى الصفحة وتبويب «التنزيلات» | كل الأنواع، لكل ربع على حدة، مع سجل الملفات المنشأة |
| صفحة الهدف | نتيجة الهدف |
| صفحة المؤشر | نتيجة المؤشر مع أرباعه وسجل تحديثاته وتفاصيل الحساب |
| صفحة المشروع | المشروع ومهامه وسجل نقلها |
| صفحة الربع | خطة الربع ونتائجه |
| «التقارير والتنزيلات» | منشئ ملفات لأي خطة متاحة لك، وسجل ملفاتك |
| لوحة الرئيس / مركز التخطيط | التقرير الشامل لأداء الجمعية (مقارنة المناصب) |

## الخيارات والصيغ

| المحتوى | PDF | DOCX | XLSX | CSV | ZIP |
|---|:-:|:-:|:-:|:-:|:-:|
| الخطة كاملة | ✓ | ✓ | ✓ | ✓ | |
| خطة ربع محدد | ✓ | ✓ | ✓ | ✓ | |
| نتائج الخطة السنوية (حتى نهاية ربع) | ✓ | ✓ | ✓ | ✓ | |
| نتائج ربع محدد | ✓ | ✓ | ✓ | ✓ | |
| نتيجة هدف أو مؤشر | ✓ | ✓ | ✓ | ✓ | |
| مشروع ومهامه | ✓ | ✓ | ✓ | ✓ | |
| حزمة السنة كاملة | | | | | ✓ |
| تقرير شامل لأداء الجمعية | ✓ | | ✓ | ✓ | |

- **PDF**: للطباعة والمشاركة؛ عرضي A4، خط Cairo، شعار الجمعية، ترقيم الصفحات، وعلامة مائية «مسودة» للخطط غير المعتمدة.
- **DOCX**: نسخة قابلة للتحرير (من اليمين لليسار).
- **XLSX**: ورقة «ملخص» + ورقة لكل جدول + ورقة «بيانات رقمية» بأرقام خام قابلة للحساب + «سجل التحديثات»؛ كل الأوراق من اليمين لليسار.
- **CSV**: بيانات المؤشرات والتحديثات بترميز UTF-8 مع BOM ليفتح بالعربية في Excel.
- **ZIP** (حزمة السنة): `00-index.csv` فهرس الملفات، الخطة PDF وDOCX، تقرير لكل ربع من الأرباع الأربعة، النتائج السنوية XLSX، وبيانات المؤشرات والتحديثات CSV.

## خطوات التنزيل

1. اختر الصيغة واضغط «تنزيل».
2. تظهر **معاينة** قبل الإنشاء: المنصب، السنة، الربع، رقم نسخة الخطة، تاريخ البيانات، حالة الاعتماد (معتمدة / مسودة)، مصدر الأرقام (حساب مباشر أو لقطة إقفال)، نسخة قواعد الحالات، واسم الملف.
3. «إنشاء الملف» ثم «تنزيل الملف الآن». يبقى الملف في سجلك لتنزيله لاحقًا.

## ما يحمله كل ملف في رأسه

اسم المنصب، السنة، الربع (أو «السنة كاملة»)، رقم النسخة (`v1`، `v2`… أو «مسودة غير معتمدة (v0)»)، تاريخ البيانات (آخر اعتماد لتحديث)، تاريخ إصدار الملف، وحالة الخطة: **مسودة** أو **معتمدة**. ويتضمن اسم الملف نفسه المنصب والسنة والربع والنسخة، مثل `results_quarter-engineering-2026-Q2-v1.pdf`.

## من يستطيع التنزيل

| المستخدم | المسموح |
|---|---|
| صاحب المنصب | ملفات خطته ونتائجها فقط |
| الرئيس، مسؤول التخطيط، أعضاء الإدارة التنفيذية المعتمدون | أي خطة، والتقرير الشامل |
| المفوّض بالاعتماد | ملفات الخطط التي تنتظر قراره فقط |
| مدير النظام التقني | لا شيء من الخطط |

يُتحقق من الصلاحية **ثلاث مرات**: عند المعاينة، وعند الإنشاء، وعند كل تنزيل. إن سُحبت صلاحية شخص (مثل إيقاف عضويته التنفيذية) فلن يستطيع تنزيل حتى الملفات التي أنشأها سابقًا. يُسجَّل من أنشأ كل ملف ومتى، وكل عملية تنزيل (المستخدم، الوقت، العنوان).

## مطابقة الأرقام

- الملف يُبنى من نفس مصدر النتائج الذي تعرضه الشاشات (`App\Services\Results`)، فالأرقام متطابقة.
- الربع المغلق يُقرأ من لقطة إقفاله؛ لذا تبقى تقارير الأرباع المغلقة كما هي حتى لو عُدّلت الخطة لاحقًا بطلب تعديل.
- كل نسبة معنونة بأساس مقارنتها: «الإنجاز مقابل مستهدف النصف الأول: 80%»، «الفجوة عن مستهدف النصف الأول: 1 برنامج»، «الإنجاز مقابل المستهدف السنوي: 33.3%».
- المؤشر الذي لم يحن قياسه يظهر «لم يستحق بعد»، والمستحق بلا بيانات معتمدة «بيانات ناقصة» — لا صفرًا.
- التحديثات بانتظار التحقق لا تدخل في الأرقام وتُذكر منفصلة.

## تعديل ملف بعد تنزيله

الملف نسخة مستقلة. تعديل DOCX أو XLSX بعد تنزيله **لا يغيّر شيئًا في النظام**. لتغيير الخطة: عدّل المسودة، أو قدّم «طلب تعديل الخطة» إن كانت معتمدة.
